## Failures corrected before passing acceptance

- The first template browser run was 4 PASS / 1 FAIL because a decorative manual-link arrow entered the accessible name. The arrow is now hidden from accessibility, and the complete local/public suites passed 5/5. Initial evidence remains in `.local/evidence-i18n/root-first-run/`.
- The pilot copier originally excluded a legitimate src/storage module. Its filter now distinguishes source modules from runtime storage; two source files were restored and the unchanged API compiled.
- The first pilot Next build inherited NODE_ENV=development, producing a production-build error. The operator runner now builds Next with production explicitly and scopes file tracing to the pilot root.
- Initial local registration returned 403 because the existing product deliberately defaults ALLOW_REGISTRATION off. Only the disposable local environment enables it; the original policy and production settings were preserved.
- The first pilot browser amount assertion exposed the legacy fixture/expectation mismatch described above. It was retained as a negative test, not bypassed with a 200-status assertion.

## Delivery checks

Final lint passed six tasks and type checking passed eight tasks (`.local/i18n-lint-final.log`, `.local/i18n-types-final.log`). The final initializer smoke verifies both README titles, preserves an existing private environment and rejects invalid/traversal names without mutation (`.local/i18n-init-smoke.log`). Public verified-TLS, DNS, health/readiness, unauthenticated 401/request ID/cache headers and the four existing application endpoints passed (`.local/i18n-public-baseline.log`).

The budget checker now recursively counts route chunks; the previous top-level-only metric undercounted assets. The new regression proves nested assets cannot bypass the limit and rejects invalid limits (one passing Node test). The actual current output is **16 chunks, 878.1 KB raw / 278.5 KB aggregate gzip, within the 300 KB limit** (`.local/i18n-budget.log`, `.local/i18n-budget-regression.log`). Aggregate gzip is not per-route transferred bytes, First Load JS or a performance benchmark. CI/deploy workflows include this regression; Actions execution remains NOT_RUN.

The new workspace API and migration images built successfully on Linux. A separate labelled disposable volume passed both versioned migrations, verified no seeded/default account, and exercised the packaged Prisma client as UID 1000: creating a default USER and persisted owner/project relationship. The check removed its temporary volume and did not restart the live API or touch its database (`.local/i18n-api-package-resume.log`). An initial operator log-reader stalled on separate Docker stderr output; draining both SSH streams fixed the operator helper before resuming the isolated smoke. This check does not turn the separate InvoiceFlow Prisma 5 Windows CLI failure into a pass.
