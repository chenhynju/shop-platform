## 当前实现与边界

- Merchant、Store、MerchantMembership、PlatformMembership 独立建模；商品归属商家及店铺，订单行保留成交时商家快照。全局 User.role 不授予新后台访问权限。
- 顾客、商家、平台分别使用独立 cookie 和 Session.audience；服务端按 API 路径选取会话，不能通过改 cookie 名交换 token。已有顾客会话迁移为 customer。
- 每次商家请求核验有效成员关系及商家状态；有多个商家时必须显式选择有权上下文。店主、商品、履约、查看职责按写操作限制。首批每商家一个店铺和店主。
- 商家可创建/修改自己的样例商品、增加测试库存、查看自己的订单行及录入内部履约完成记录。不能查看或修改其他商家商品/库存/订单行。内部记录不代表承运商揽收或真实物流接通。
- 平台首版提供商家/成员、商品、订单和操作记录查看；没有开放审批、退款、资金与结算账号写操作。MFA、正式商家入驻审核、员工邀请、部分包裹与售后仍待实现，不能宣称完整工业级电商后台。

- 原商家入口 `/shop/merchant` 保留兼容。原五个样例商品不随机分配商家，平台显示为历史样例目录。
- 不改变美加首发方向，不开启真实支付、商家打款或物流，不替用户签约和付款。
