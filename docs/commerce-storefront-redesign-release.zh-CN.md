# 商城视觉改版 v2 执行记录

范围：顾客商城首页、列表、搜索、分类、商品详情、购物车/订单/账号的统一视觉。复用既有 API；不部署未完成的商家模型、支付或物流增量。

## 实现

搜索优先的紧凑商城页头、主题推荐与真实目录分类、URL 筛选/排序、库存状态、商品详情与库存限制数量加购、购物说明。桌面四列、手机两列。未添加虚构评分、销量、折扣、配送时效。样例商品仍以 CNY 展示；付款仍为模拟。

分类为现有五个样例商品的展示分组，不代表后端类目或 SKU 规格系统已经实现。
